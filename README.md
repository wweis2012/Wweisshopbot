# Wweis store — Telegram-магазин

Готовый бот-магазин с каталогом товаров, корзиной и оформлением заявки.

## Товары
- Бравл пасс — 200 ₽
- Бравл пасс+ — 300 ₽
- Про пасс — 800 ₽
- 2000 гемов — 1500 ₽
- 950 гемов — 950 ₽

## Важно
Бот не принимает онлайн-оплату. После оформления заявки данные заказа отправляются администратору.

## Запуск
1. Установи Python 3.11+.
2. Создай бота через официального BotFather в Telegram и получи токен.
3. Скопируй `.env.example` в `.env`.
4. Укажи `BOT_TOKEN` и `ADMIN_CHAT_ID`.
5. Установи зависимости: `pip install -r requirements.txt`
6. Запусти: `python bot.py`

Не публикуй токен бота.
